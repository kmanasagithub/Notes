# Chapter 4.12: Sorting and Pagination in Spring Data JPA

# Why Do We Need Sorting and Pagination?

Imagine a table:

```text
Employee

ID    Name      Salary
-----------------------
1     John      50000
2     Alice     70000
3     Bob       40000
...
100000 records
```

If a client requests all records:

```java
repository.findAll();
```

Problems:

```text
High Memory Usage
Slow Response
Heavy Database Load
Poor User Experience
```

To solve this, Spring Data JPA provides:

1. Sorting
2. Pagination

---

# Part 1: Sorting

# Definition

Sorting means arranging records in a specific order.

Examples:

```text
Name Ascending
Name Descending
Salary Ascending
Salary Descending
Created Date Descending
```

---

# Real World Examples

## E-Commerce

Sort products by:

```text
Price Low To High
Price High To Low
Newest First
Most Popular
```

---

## Hotel Booking

Sort hotels by:

```text
Price
Rating
Distance
Popularity
```

---

## Employee Management

Sort employees by:

```text
Name
Salary
Joining Date
```

---

# Method 1: Sorting Using Method Names

Spring Data JPA can generate sorting queries automatically.

---

## Ascending

```java
List<Employee> findAllByOrderByNameAsc();
```

Generated SQL:

```sql
SELECT *
FROM employee
ORDER BY name ASC;
```

---

## Descending

```java
List<Employee> findAllByOrderByNameDesc();
```

Generated SQL:

```sql
SELECT *
FROM employee
ORDER BY name DESC;
```

---

# Multiple Fields

```java
List<Employee>
findAllByOrderByDepartmentAscSalaryDesc();
```

SQL:

```sql
ORDER BY department ASC,
         salary DESC
```

---

# Problem with Method-Based Sorting

Suppose users can sort by:

```text
Name
Salary
Age
Department
CreatedAt
```

You would need many methods.

Not scalable.

---

# Method 2: Sorting Using Sort Class

Most common approach.

---

## Repository

```java
public interface EmployeeRepository
extends JpaRepository<Employee,Long> {
}
```

---

## Service

```java
Sort sort =
Sort.by("name");
```

Usage:

```java
employeeRepository.findAll(sort);
```

---

Generated SQL

```sql
ORDER BY name ASC
```

---

# Descending Sort

```java
Sort sort =
Sort.by(
Sort.Direction.DESC,
"name"
);
```

SQL:

```sql
ORDER BY name DESC
```

---

# Multiple Column Sorting

```java
Sort sort =
Sort.by(
    Sort.Order.asc("department"),
    Sort.Order.desc("salary")
);
```

Generated SQL:

```sql
ORDER BY department ASC,
         salary DESC
```

---

# Sorting Flow

```text
Client Request
       ↓
Sort.by("salary")
       ↓
Repository
       ↓
Hibernate
       ↓
ORDER BY salary
       ↓
Database
```

# Part 2: Pagination

# Definition

Pagination means fetching data page by page instead of loading everything at once.

---

# Why Pagination?

Suppose:

```text
Product Table
1 Million Rows
```

Bad:

```java
findAll()
```

Loads:

```text
1 Million Records
```

into memory.

---

Good:

```java
PageRequest.of(0,10)
```

Loads:

```text
Only 10 Records
```

---

# Real World Examples

## Amazon

```text
Page 1
Page 2
Page 3
...
```

---

## Google Search

```text
Showing 1-10 Results
Next Page
```

---

## LinkedIn

```text
Posts Loaded In Chunks
```

---

# Key Concepts

---

# Page

A single chunk of data.

Example:

```text
100 Records

Page Size = 10

Pages:

Page 0 → Records 1-10

Page 1 → Records 11-20

Page 2 → Records 21-30
```

---

# Pageable

Interface containing pagination information.

```java
Pageable pageable;
```

Stores:

```text
Page Number
Page Size
Sorting
```

---

# PageRequest

Implementation of Pageable.

Used to create pagination objects.

```java
Pageable pageable =
PageRequest.of(0,10);
```

Meaning:

```text
Page Number = 0

Page Size = 10
```

---

# Repository Method

JpaRepository already provides:

```java
Page<T> findAll(Pageable pageable);
```

---

# Example

```java
Pageable pageable =
PageRequest.of(0,5);

Page<Employee> employees =
employeeRepository.findAll(pageable);
```

Generated SQL:

```sql
SELECT *
FROM employee
LIMIT 5 OFFSET 0;
```

---

# Understanding OFFSET

Suppose:

```text
Page Size = 5
```

---

## Page 0

```java
PageRequest.of(0,5)
```

SQL:

```sql
LIMIT 5 OFFSET 0
```

Returns:

```text
1-5
```

---

## Page 1

```java
PageRequest.of(1,5)
```

SQL:

```sql
LIMIT 5 OFFSET 5
```

Returns:

```text
6-10
```

---

## Page 2

```java
PageRequest.of(2,5)
```

SQL:

```sql
LIMIT 5 OFFSET 10
```

Returns:

```text
11-15
```

---

# Page Object

Returned by:

```java
Page<Employee>
```

Contains:

```text
Data
Total Pages
Total Elements
Current Page
Page Size
```

---

# Example

```java
Page<Employee> page =
employeeRepository.findAll(pageable);
```

Useful methods:

```java
page.getContent();

page.getTotalPages();

page.getTotalElements();

page.getNumber();

page.getSize();

page.hasPrevious();
```

# Combining Pagination and Sorting

Most common interview topic.

---

## Example

```java
Pageable pageable =
PageRequest.of(
    0,
    10,
    Sort.by("salary")
);
```

---

Generated SQL

```sql
SELECT *
FROM employee
ORDER BY salary
LIMIT 10 OFFSET 0
```

---

```java
Pageable pageable =
PageRequest.of(
    0,
    10,
    Sort.by(
        Sort.Direction.DESC,
        "salary"
    )
);
```

SQL:

```sql
ORDER BY salary DESC
LIMIT 10 OFFSET 0
```

# REST API Example

## Controller

```java
@GetMapping("/employees")
public Page<Employee> getEmployees(
        @RequestParam int page,
        @RequestParam int size){

    Pageable pageable =
            PageRequest.of(page,size);

    return repository.findAll(pageable);
}
```

Request:

```http
GET /employees?page=0&size=5
```

# Common Interview Questions

## What is Sorting?

Arranging records in a specific order using ORDER BY.

---

## What is Pagination?

Fetching records page by page rather than loading all records.

---

## Difference Between Page and Pageable?

Page:

```text
Result
```

Pageable:

```text
Request Information
```

---

## What is PageRequest?

Concrete implementation of Pageable.

---

## Why Use Pagination?

To reduce memory consumption and improve performance.

---

## Difference Between findAll() and findAll(Pageable)?

findAll():

```text
Loads Entire Table
```

findAll(Pageable):

```text
Loads Required Records Only
```
